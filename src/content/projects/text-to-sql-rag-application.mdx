A natural-language-to-SQL pipeline built to production standards rather than demo
standards: schema-aware retrieval over ChromaDB, a FastAPI service layer, and an
evaluation harness that runs against a fixed question set on every change.

Architecture decisions are recorded as ADRs, so the reasoning behind each trade-off
is legible after the fact.
